display: flex

Kisi bhi element pe display: flex lagate hi wo ek flex container ban jaata hai, aur uske direct children automatically flex items ban jaate hain. Bina kisi float ya inline-block jugaad ke items ek row mein side-by-side aa jaate hain — ye flexbox ka default behaviour hai.

.container {
  display: flex;
}

flex-direction

Ye decide karta hai ki main axis kis direction mein chalega — items row mein jaayenge ya column mein, aur normal order mein ya reverse mein.

.row        { flex-direction: row; }         /* default, left → right */
.row-rev    { flex-direction: row-reverse; } /* right → left */
.column     { flex-direction: column; }      /* top → bottom */
.column-rev { flex-direction: column-reverse; } /* bottom → top */

flex-wrap

Default mein flexbox saare items ko ek hi line mein fit karne ki koshish karta hai, chahe wo shrink hi kyun na ho jaayein. flex-wrap: wrap lagane se jab space kam pade, items agli line mein wrap ho jaate hain.

.container {
  display: flex;
  flex-wrap: wrap; /* nowrap (default) | wrap | wrap-reverse */
}
nowrap (default) — items shrink ho jaate hain

align-items

Items ko cross axis (main axis ke perpendicular — default: vertical) ke along align karta hai. Ek single line ke andar items kaise align honge, ye control karta hai.

  display: flex;
  align-items: stretch | flex-start | flex-end | center | baseline;
}

Flex Item Properties

flex-grow

Batata hai ki container mein jo extra khaali space bacha hai, usme se ek item kitna hissa lekar grow kare, doosre items ke comparison mein. Default value 0 hoti hai (grow nahi karta).

.item-2 {
  flex-grow: 2; /* isse doosron ke comparison mein 2x zyada space lega */
}
grow: 1
grow: 2
grow: 3

flex-shrink

Batata hai ki jab container mein space kam pade, to ek item doosron ke comparison mein kitna shrink ho. Default value 1 hoti hai (sab equally shrink hote hain). 0 set karne se wo item shrink hi nahi hoga.

.item-2 {
  flex-shrink: 0; /* ye item kabhi shrink nahi hoga */
}
shrink: 1
shrink: 0
shrink: 3

flex-basis

Item ki starting size set karta hai — grow/shrink hone se pehle. Ye width jaisa hi hai but flex context mein — width ke bajaye flex-basis ko priority milti hai.

.item {
  flex-basis: 200px; /* auto (default) | length | % | content */
}

order

HTML mein items ka source order badle bina, unka visual order change karta hai. Default value 0 hoti hai — jitna kam number, utna pehle dikhega.

.item-1 { order: 3; }
.item-2 { order: 1; }
.item-3 { order: 2; }
