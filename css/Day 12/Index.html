Day 20 — Transitions, Animations & CSS Variables

1. transition

Definition: transition ek property hai jo kisi CSS value ke change ko instant hone ki jagah smooth (animated) banati hai — jab woh value hover, click, ya JS se change hoti hai. Syntax: transition: property duration timing-function; 

.transition-demo {
  background: var(--primary);
  transition: background 0.4s ease, transform 0.4s ease;
}

.transition-demo:hover {
  background: orangered;
  transform: scale(1.1);
}

2. transform

Definition: transform element ki position, size, ya angle change karta hai bina layout todhe. Common values: translate() (move), scale() (size), rotate() (angle), skew() (tilt).

3. @keyframes and animation

Definition: @keyframes se tum ek animation ke multiple stages (0% se 100%) define karte ho. animation property us keyframe ko element pe apply karti hai — bina hover/click ke, khud chalti hai. Syntax: animation: name duration timing-function iteration-count; 

@keyframes bounce {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-40px); }
  100% { transform: translateY(0); }
}

.bounce-ball {
  animation: bounce 1.2s ease-in-out infinite;
}

4. CSS Custom Properties (--variable) & Theming

Definition: CSS variables (--name) reusable values hote hain, usually :root mein define kiye jaate hain aur var(--name) se use hote hain. Theming (light/dark mode) mein inhi variables ki values ko kisi class (jaise .dark) ke andar overwrite kiya jaata hai.

Yeh card apne colors var(--primary) jaisi CSS variables se le raha hai.

:root {
  --primary: #6c5ce7;
  --bg: #ffffff;
  --text: #222222;
}

.dark {
  --bg: #111111;
  --text: #ffffff;
}

.theme-card {
  background: var(--bg);
  color: var(--text);
  transition: background 0.4s ease, color 0.4s ease;
}
