2. Mobile-First vs Desktop-First

Definition: Mobile-first = base CSS is written for small screens, then min-width queries ADD styles for bigger screens. Desktop-first = base CSS is for big screens, then max-width queries OVERRIDE for smaller screens. Mobile-first is the modern recommended approach.

3. max-width, min-width Strategies

Definition: max-width = upper limit (element won't grow past it). min-width = lower limit (element won't shrink below it).

This container has max-width: 600px — try resizing the window wider, it will stop growing at 600px and stay centered.
min-width: 150px sidebar

4. Responsive Units & clamp(), min(), max()

Definition: clamp(min, preferred, max) lets a value scale fluidly between two limits. min() picks the smaller of two values, max() picks the larger.

clamp(1.2rem, 4vw, 2.5rem) — resize window to see me scale
width: min(90%, 500px) | padding: max(1rem, 3vw)
