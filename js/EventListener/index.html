1.addEventListener kya hota hai?

Pehle hum onclick="..." jaisa inline tareeka use karte the HTML mein. Lekin real projects mein hum JS se hi listener attach karte hain — clean aur flexible tareeka hai.

const btn = document.querySelector("#myBtn");

btn.addEventListener("click", function() {
  console.log("Button dabaya gaya!");
});

syntax element.addEventListener(eventType, callbackFunction)

Fayda ye hai ki ek hi element pe multiple listeners laga sakte ho, aur baad mein removeEventListener se hata bhi sakte ho.

Ye sabse zyada use hone wale events hain — inhe achhe se samajh lo, 90% kaam inhi se chalta hai.

click jab user kisi element pe click kare

mouseover jab mouse kisi element ke upar jaaye (hover)

Mouse le jao yahan

key ka naam yahan dikhega

submit jab form submit ho (button ya Enter dabane par)

change jab select/checkbox/input ki value change ho aur focus hate hi trigger ho

3.Event Object, preventDefault() & stopPropagation()

Jab bhi koi event fire hota hai, JS automatically ek event object bana ke callback function mein pass kar deta hai. Isme event ki puri detail hoti hai — kaunsa element, kaunsi key, coordinates, sab kuch.

btn.addEventListener("click", function(event) {
  console.log(event.target);   // kis element pe click hua
  console.log(event.type);     // event ka type: "click"
});

preventDefault() — kisi event ka default behaviour rokta hai.

Example: form submit hote hi normally page reload ho jaata hai. preventDefault() se wo rukta hai.

Submit karke dekho — page reload nahi hoga

stopPropagation() — event ko upar wale (parent) elements tak jaane se rokta hai. Isse pehle "bubbling" samajhte hain niche 👇

4.Event Bubbling & Delegation

Bubbling: jab ek nested element pe event fire hota hai, to wo event uske andar se bahar ki taraf — parent → grandparent — tak "bubble up" karta hai, jaise pani mein bubble upar jaata hai.

Agar Inner ke click handler mein event.stopPropagation() laga dete, to sirf "Inner clicked" print hota — Middle aur Outer tak event pahunchta hi nahi.

Event Delegation: ye bubbling ka hi smart use hai. Instead of har child pe alag-alag listener lagane ke, hum ek hi listener parent pe laga dete hain aur event.target check karte hain ki click kis child pe hua.

// 100 li items ho tab bhi ek hi listener kaafi hai
list.addEventListener("click", function(event) {
  if (event.target.tagName === "LI") {
    console.log("Clicked:", event.target.textContent);
  }
});
